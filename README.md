# 中际旭创交易量分析

分析中际旭创(300308.SZ)近3个月每分钟交易数据，找出买入量和卖出量最大的10分钟区间。

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

直接运行脚本：

```bash
python analyze_trading.py
```

脚本会自动：
1. 获取近3个月（90天）的交易数据
2. 尝试使用tick数据区分买卖方向
3. 按10分钟窗口聚合数据
4. 找出买入量和卖出量最大的10分钟区间
5. 将详细统计结果保存为CSV文件

## 输出文件

- `买入量_10分钟统计.csv` - 每个10分钟区间的买入量统计
- `卖出量_10分钟统计.csv` - 每个10分钟区间的卖出量统计
- `成交量_10分钟统计.csv` - 如果无法区分买卖方向，则输出总成交量统计

## 注意事项

1. 需要tushare账户并开通相应数据权限
2. tick数据需要较高权限，如果无法获取，脚本会自动降级使用1分钟K线数据
3. 数据获取可能需要一些时间，请耐心等待
