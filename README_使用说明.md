# 中际旭创股票价格预测模型 - 使用说明

## 快速开始

### 方法1：双击运行（推荐）

直接双击 `运行预测模型.bat` 文件，程序会自动：
- ✅ 查找 Python（包括 `C:\Users\syy\Python313`）
- ✅ 安装所有依赖包
- ✅ 运行预测模型
- ✅ 生成所有结果文件

### 方法2：PowerShell运行

右键点击 `运行预测模型.ps1`，选择"使用PowerShell运行"

### 方法3：命令行运行

```bash
python predict_stock_price_advanced.py
```

## 关于警告信息

如果看到以下警告：
```
WARNING: The scripts ... are installed in 'C:\Users\syy\Python313\Scripts' which is not on PATH.
```

**这是正常的，不影响程序运行！**

这个警告只是提示某些脚本工具不在系统PATH中，但我们的程序不直接使用这些工具，所以可以忽略。

如果想消除警告，可以：
1. 将 `C:\Users\syy\Python313\Scripts` 添加到系统PATH环境变量
2. 或者直接忽略（推荐，因为不影响功能）

## 生成的文件

运行完成后会生成以下文件：

1. **中际旭创_价格预测.html** - 交互式预测结果网页

## 数据获取状态

程序会尝试获取多种数据源，但某些数据可能需要更高的Tushare权限。详细的数据获取状态请参考 **`数据获取状态.md`** 文件。

### 通常无法获取的数据（不影响模型运行）

以下数据通常需要更高权限，获取失败不影响模型运行：
- ❌ **行业指数**: 半导体、通信、电子等行业指数（需要更高权限）
- ❌ **机构持仓数据**: 基金持仓数据（接口可能不可用）
- ❌ **宏观经济指标**: 利率、汇率、M2货币供应量（需要更高权限）
- ⚠️ **部分财务数据**: 某些财务指标可能需要更高权限

### 通常可以获取的数据

以下数据通常可以正常获取：
- ✅ **中际旭创股票数据**: 必需数据
- ✅ **大盘指数**: 创业板指、深证成指、沪深300等
- ✅ **外部市场**: 比特币、美股指数（通过yfinance）
- ✅ **技术指标**: 自动计算，无需外部数据

**注意**: 即使某些数据无法获取，模型仍会使用可用数据正常运行。

## 常见问题

### Q: 显示"未找到Python"
A: 脚本会自动查找多个常见位置，包括 `C:\Users\syy\Python313`。如果还是找不到，请：
- 检查Python是否已安装
- 手动修改 `运行预测模型.bat`，在开头添加：`set PYTHON_PATH=C:\Users\syy\Python313\python.exe`

### Q: SHAP库未安装
A: 程序会自动检测并安装缺失的包，包括SHAP。如果安装失败，可以手动运行：
```bash
pip install shap
```

### Q: 程序运行很慢
A: 这是正常的，因为需要：
- 获取2年的历史数据
- 训练多个机器学习模型
- 生成多个图表和分析文件

通常需要5-15分钟，取决于网络速度和电脑性能。

### Q: 某些数据获取失败
A: 这可能是由于：
- Tushare API权限不足
- 网络连接问题
- 某些数据源暂时不可用

程序会继续运行，使用可用的数据。详细的数据获取状态请参考 **`数据获取状态.md`** 文件。

### Q: 特征相关性和特征重要性对比图是空白的
A: 这可能是由于：
- 数据传递问题（已修复）
- 某些特征数据缺失导致无法计算相关性
- 模型不支持特征重要性

程序已改进数据处理逻辑，现在应该能正常显示。如果仍然空白，请检查控制台输出的错误信息。
