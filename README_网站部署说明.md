# 中际旭创股票价格预测网站 - 部署说明

本说明介绍如何将预测网站分享给其他人访问。

## 方法1: 本地Web服务器（局域网内分享）

### 快速启动

1. **双击运行** `启动Web服务器.bat`
2. 服务器启动后，会显示访问地址
3. 将显示的局域网地址（如 `http://192.168.1.100:8000/中际旭创_价格预测.html`）分享给同一网络内的其他人

### 手动启动

```bash
python 启动Web服务器.py
```

### 访问地址

- **本地访问**: http://localhost:8000/中际旭创_价格预测.html
- **局域网访问**: http://您的IP地址:8000/中际旭创_价格预测.html

### 注意事项

- ✅ 其他人需要与您在**同一个局域网**（同一WiFi/网络）
- ✅ 确保防火墙允许端口 8000 的访问
- ✅ 按 `Ctrl+C` 停止服务器
- ❌ 无法跨网络访问（如从外网访问）

## 方法2: GitHub Pages（公网访问，推荐）

适合需要公网访问的场景，完全免费。

### 快速步骤

1. **创建GitHub账号**（如果没有）：https://github.com/signup
2. **创建新仓库**：
   - 登录GitHub
   - 点击右上角 "+" → "New repository"
   - 仓库名：`stock-prediction`（或任意名称）
   - 选择 "Public"
   - 点击 "Create repository"

3. **上传文件**：
   - 在仓库页面点击 "uploading an existing file"
   - 上传以下文件：
     - `中际旭创_价格预测.html`
     - `中际旭创_价格预测模型.png`
     - `中际旭创_多因素散点图.png`
     - `中际旭创_特征重要性详细分析.png`
     - `中际旭创_所有因素散点图_第1页.png`
   - 点击 "Commit changes"

4. **启用GitHub Pages**：
   - 在仓库页面点击 "Settings"
   - 左侧菜单找到 "Pages"
   - Source 选择 "main" 分支和 "/ (root)"
   - 点击 "Save"

5. **访问网站**：
   - 几分钟后，访问：`https://您的用户名.github.io/stock-prediction/中际旭创_价格预测.html`

详细说明请查看：`部署到GitHub_Pages.md`

## 常见问题

### Q: 为什么别人无法访问我的本地服务器？

A: 可能的原因：
1. 不在同一网络（需要同一WiFi/局域网）
2. 防火墙阻止了端口 8000
3. IP地址输入错误

**解决方法**：
- Windows防火墙：设置 → 防火墙 → 允许应用通过防火墙 → 允许Python
- 确认IP地址：运行 `ipconfig` 查看本机IP

### Q: GitHub Pages 访问很慢怎么办？

A: GitHub Pages 在国内访问可能较慢，可以：
1. 使用VPN/代理
2. 使用国内CDN加速
3. 考虑使用 Netlify 或 Vercel（国内访问更快）

### Q: 如何自动更新网站？

A: 每次运行预测模型后，可以：
1. 手动上传新文件到GitHub
2. 使用Git命令自动推送（见 `部署到GitHub_Pages.md`）
3. 设置GitHub Actions自动部署
