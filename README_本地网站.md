## 🚀 两种方式访问网站

### 方式1: 直接打开HTML文件（最简单）

**操作**: 双击运行 `直接打开网站.bat`

**特点**:
- ✅ 最简单，无需任何配置
- ✅ 可以离线使用
- ❌ 只能在本机访问
- ❌ 图片可能无法正常显示（如果路径问题）

### 方式2: 启动本地Web服务器（推荐）

**操作**: 双击运行 `启动本地网站.bat`

**特点**:
- ✅ 可以在局域网内分享给他人
- ✅ 支持多设备访问
- ✅ 所有资源（图片、CSS等）正常显示
- ✅ 更接近真实网站体验

**访问地址**:
- 本地: `http://localhost:8000/中际旭创_价格预测.html`
- 局域网: `http://您的IP地址:8000/中际旭创_价格预测.html`

**停止服务器**: 在服务器窗口按 `Ctrl+C`

## 📋 使用步骤

### 步骤1: 启动网站

**选择一种方式**:

**A. 直接打开**:
```
双击: 直接打开网站.bat
```

**B. Web服务器**（推荐）:
```
双击: 启动本地网站.bat
```

### 步骤2: 访问网站

- **直接打开**: 网站会自动在浏览器中打开
- **Web服务器**: 
  - 本机会自动打开浏览器
  - 或手动访问显示的地址

### 步骤3: 分享给他人（仅Web服务器方式）

1. **查看IP地址**: 服务器启动后会显示，例如 `http://192.168.1.100:8000`
2. **分享地址**: 将地址发送给同一WiFi/网络内的其他人
3. **他们访问**: 在浏览器中输入地址即可

**注意**:
- 其他人需要与您在同一个局域网（同一WiFi/网络）
- 确保防火墙允许端口8000的访问
- 服务器运行时，其他人才能访问

## 🔄 更新网站

每次运行预测模型后：

1. **运行**: `运行预测模型.bat`（生成新的HTML）
2. **刷新浏览器**: 按 `F5` 或 `Ctrl+R` 刷新页面

如果需要在公网访问（不在同一网络也能访问），可以使用：

详细步骤请查看: `README_网站部署说明.md`

## ❓ 常见问题

### Q: 直接打开HTML文件，图片无法显示？

**A**: 使用Web服务器方式（`启动本地网站.bat`），所有资源都会正常显示

### Q: Web服务器无法启动？

**A**: 
- 检查Python是否已安装
- 检查端口8000是否被占用
- 尝试关闭防火墙

### Q: 其他人无法访问我的Web服务器？

**A**: 
- 确认在同一局域网
- 检查防火墙设置
- 确认服务器正在运行
